# RinseGo — Full-Stack Doorstep Car Care Platform

Complete full-stack application:
- **Frontend**: React 18 + Vite
- **Backend**: Node.js + Express REST API + JWT Auth + Multer Photo Uploads
- **Database**: PostgreSQL 16 (`database/init.sql`)
- **Reverse Proxy**: Nginx (`nginx/nginx.conf`)

## Quick Start (Docker)
```bash
cp .env.example .env
docker-compose up --build -d
```
Open **http://localhost** in your browser.
